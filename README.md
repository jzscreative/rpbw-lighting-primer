# Renzo Piano for lighting designers

A one-page primer on Renzo Piano Building Workshop for lighting designers. Static HTML: `index.html`, `site.css`, `img/`, `fonts/`, `assets/`. No build step.

Publish: push this folder to a GitHub repository and enable Pages (Settings > Pages > deploy from branch, root).
Note: a Pages site from a private repository is still publicly reachable at its URL unless the org is on GitHub Enterprise Cloud with private Pages. The page carries `noindex`. Fonts (BH Brandon Text) and photographs are licensed/third-party material for internal study.
